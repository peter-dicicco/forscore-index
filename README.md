# forscore-index
I've had a tough time finding good index files for ForScore for some fake and real books.  This project intends to create an area where better quality indexes exist.

The first one I worked on was for the Django Fakebook.  I found a json files in the [FakeBookIndex](https://github.com/milnak/FakeBookIndex) repo that I used as a starting point.  The improvments I made are: 1. I added the end page and 2. I removed the duplicate entries for multi page songs.  Adding the end page to a ForScore index is important so the songs can be used in playlists.
